## 🏛️ Architecture Overview

The portfolio is architected as an ultra-minimalist, handcrafted multi-page engineering site inspired by top industry builders (Rauno Freiberg, Paco Coursey, Lee Robinson, and Linear/Vercel design standards).

```
deepeshpankaj-portfolio/
├── index.html                      # Minimalist matte black landing page
├── projects.html                   # Complete categorized engineering directory (8+ systems)
├── highlights.html                 # Peer-reviewed research (ICAIEST-2026), summits & photo archive
├── about.html                      # Systems engineering philosophy, stack & contact
├── style.css                       # Handcrafted matte-black design system & precision framing
├── script.js                       # Vanilla interactions (lightbox, active nav, copy toast)
├── image/                          # Genuine photographic & project assets
├── public/                         # Public assets & icons mirrored for static delivery
├── netlify.toml                    # Netlify production build & redirect configuration
├── vite.config.ts                  # Multi-page build configuration
└── package.json                    # Build scripts & dependencies
```

## 🎨 Design System & Anti-AI-Slop Standards

- **Strict Monochrome Matte Black Palette**:
  - Primary Background: `#09090b` (Deep Matte Carbon Black)
  - Elevated Card / Surface: `#111113`
  - Subtle Hairline Borders: `#1f1f23` (Hover: `#3f3f46`)
  - Primary Text: `#f4f4f5` (Crisp Off-White)
  - Secondary Text: `#a1a1aa` (Muted Zinc)
  - Monospace Tech Tags: `#71717a`
- **Zero-AI-Slop**:
  - No neon gradients, glowing background orbs, floating particles, decorative emojis, or skill percentage bars.
  - Authentic, restrained, precision-framed photographic assets with subtle grayscale-to-color hover transitions.
- **Typography & Layout**:
  - Headings & Body: `'Inter'`, sans-serif with tight letter spacing (`-0.02em`).
  - Metadata & Pills: `'JetBrains Mono'`, monospace (`0.78rem`).
  - Centered layout constrained between `880px` and `920px` with generous vertical breathing room.
